# 天地课堂联播台

面向港澳学校与空间站天地连线的联播协作服务：学校提交带审核链的参与计划，总控按空间站窗口与校区容量锁定场次，全程事件溯源、可断线续传、未成年人资料按角色隔离并留存访问审计。

纯 Python 3.11 标准库实现，无第三方依赖。

## 运行

```bash
python3 -m unittest          # 运行全部自动化验收（39 个用例）
python3 -m service.main      # 启动服务（默认 127.0.0.1:8000，数据目录 ./data）
```

环境变量：`HOST`、`PORT`、`DATA_DIR`（置空则仅内存运行）。事件日志持久化在 `$DATA_DIR/events.jsonl`，重启后自动重放恢复，每次排期版本均可还原。

## 架构

```
service/
  store.py    追加式事件日志（seq 连续递增，JSONL 持久化）
  domain.py   领域核心：命令在单锁内串行执行，容量校验与占位同一临界区；
              状态全部由事件重放得出（事件溯源）
  auth.py     角色矩阵：control / reviewer / school / auditor
  httpapi.py  JSON 路由、身份解析、错误映射
  main.py     服务入口
tests/        自动化验收：计划审核、场次容量、并发占位、冲突处置、
              通知失效、资料隔离、断线重连、重启还原
docs/         领域约定与接口说明
```

## 核心流程

1. **登记**：总控登记学校（含校区容量）与空间站窗口（含座位容量，窗口时间不得重叠）。
2. **计划**：学校提交参与计划（`Idempotency-Key` 去重），经初审（reviewer）→ 终审（control）的审核链。
3. **锁场**：总控按窗口容量与校区容量锁定场次，可附 `expected_version` 做乐观并发；容量校验与占位在同一临界区完成，并发占位不会超额。
4. **变更**：窗口收缩（`shrink`）超容时返回影响面与处置选项，确认后按终审时间从新到旧移除；学校退出、场次取消都会释放座位、失效相关通知并明确通知范围。
5. **通知**：变更产生的通知进入待发队列，`dispatch` 只下发有效通知，已失效（superseded）的永不下发。
6. **续传**：客户端以事件 `seq` 为最后确认点，断线后 `GET /events?since=<seq>` 续传；重试命令带原幂等键即返回原结果。

接口明细见 [docs/api.md](docs/api.md)，领域约定见 [docs/domain.md](docs/domain.md)。

## 角色速览

| 角色 | 能力 |
| --- | --- |
| control | 全部管理操作、查看未成年人资料（留审计） |
| reviewer | 计划初审、查看计划元数据（不可见学生名单） |
| school | 提交/撤回本校计划、登记与查看本校学生名单、查看本校通知 |
| auditor | 只读审计日志与事件流（学生名单已脱敏） |

调用方通过请求头声明身份：`X-Actor-Id` / `X-Actor-Role`（/ `X-School-Id`，学校角色必填）。这是演示级认证，生产环境应替换为真实鉴权网关，角色矩阵与隔离规则不变。
