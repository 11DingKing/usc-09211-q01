# 天地课堂联播台领域约定

## 记录方式

- 事件时间与接收时间分离：每条事件携带服务端 `recorded_at`；调用方可另附业务发生时间 `occurred_at`。
- 所有业务身份由调用方提供的稳定标识表示（school_id / window_id / plan_id / session_id / notification_id）。
- 事件只追加、不覆盖；审计记录（`minor_data_accessed`）同样是事件，不得以覆盖方式修改。
- 每条事件分配连续递增的 `seq`，作为断线重连的最后确认点。

## 状态机

**参与计划**：`submitted → initial_approved → approved`，任一审级可 `reject` 得 `rejected`；生效中的计划可 `withdrawn`。审核链（初审 reviewer、终审 control）完整留痕于计划内。

**场次**：`locked → cancelled`。锁定时校验：计划已通过终审、归属该窗口、未被其他场次占用、占位不超过计划人数与校区容量、窗口总占位不超过窗口容量。

**通知**：`pending → sent`；下发前若事实基础消失（学校退出、场次取消、窗口收缩移除），转为 `superseded`，永不下发。

## 并发与幂等

- 所有命令在单锁内串行执行，容量校验与占位在同一临界区完成：并发占位不会超额。
- 变更类请求接受 `Idempotency-Key`：结果随事件持久化，重放同一键返回原结果（响应头 `Idempotent-Replay: true`），不重复落事件；重启后仍有效。
- 业务 ID 天然幂等：同一 ID 相同内容重复登记返回原记录，内容不一致返回 409。
- 排期变更（锁场、取消、窗口变更、占位移除）携带单调递增的版本号；`expected_version` 不符时返回 409 及期间全部变更摘要（可解释冲突）。

## 冲突处置

- **窗口收缩**：超容时不直接变更，先返回影响面（超出座位、移除候选及顺序）与处置选项；调用方以 `resolution=auto_trim` 确认后，按终审通过时间从新到旧移除至满足容量，响应内含中文说明与通知范围。
- **学校退出**：释放占位、失效该校相关待通知、通知总控。
- **两地同时改动**：以排期版本号做乐观并发，过期版本被拒并附恢复指引。

## 未成年人资料

- 学生名单仅总控与所属学校可读；每次读取必须说明用途（`purpose`）并写入访问审计。
- 审核员不可见学生名单；审计员只读审计日志与脱敏事件流。
