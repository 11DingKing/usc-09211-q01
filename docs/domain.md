# 天地课堂联播台领域约定

## 身份与时间

- 所有业务身份（学校、校区、窗口、计划、学生、审核人）由调用方提供稳定标识。
- 事件同时记录 `event_time`（调用方业务时间）与 `received_at`（服务端接收时间）。
- 事件日志与审计记录只追加，不得以覆盖方式修改；当前状态完全由事件重放得到。

## 参与计划与审核链

- 计划由学校上报，提问征集与课后材料随计划一并归档。
- 审核链固定为“校内审核 → 总控审核”，不可越级；两级通过后总控方可占位。
- 计划上报按 `学校 + idempotency_key` 幂等；审核、占位、退出等重复操作不产生重复效果。

## 窗口、占位与排期版本

- 窗口有效席位取 `min(空间站信号容量, 校区场地容量)`。
- 占位在服务端串行校验，任何并发组合下已占席位不得超过容量。
- 每次锁定或锁定后变更都产生新的不可变排期版本，历史版本可逐条回放；
  锁定后的写操作必须携带 `expected_version`，落后即判为两地同时改动冲突。

## 冲突与通知

- 窗口缩短导致容量不足、两地基于不同版本同时改动，均登记冲突记录：
  包含可解释原因、受影响计划与学校范围、可选处置方案与建议方案。
- 冲突未处置前，相关参与者通知挂起；通知派发前按最新排期逐条复核，
  被更新通知取代或已失效的草稿一律抑制（SUPPRESSED），绝不误发。

## 未成年人资料

- 学生完整资料仅所属学校角色可访问；总控、审计员、其他学校均不可读。
- 每次访问尝试（允许或拒绝）及通知派发时的联系方式解析都记入审计。
